# 🎸 个性化吉他教学 Agent

一个基于 AI 的个性化吉他教学助手，能够根据学习者的水平和目标，提供量身定制的吉他学习方案。

## 项目简介

本项目是一个智能吉他教学 Agent，旨在帮助吉他爱好者：

- 根据自身水平（初学者 / 中级 / 高级）获取个性化学习计划
- 通过对话方式与 AI 老师互动，随时解答疑问
- 获得曲目推荐和练习建议
- 追踪学习进度，持续优化教学方案

## 快速开始

### 1. 克隆项目

```bash
git clone https://github.com/your-username/guitar-agent.git
cd guitar-agent
```

### 2. 安装依赖

```bash
pip install -r requirements.txt
```

### 3. 配置环境变量

复制 `.env.example` 为 `.env`，填入你的 API Key：

```bash
cp .env.example .env
```

### 4. 运行项目

```bash
python main.py
```
